# NAHRIM
## DEVELOPMENT OF DATA-DRIVEN SPATIAL DASHBOARD ON RAINFALL VOLUME FOR HOSPITALS IN MALAYSIA (KEDAH AND SELANGOR) BASED ON MULTIPLE DATA SOURCE.

### **Week 1**: Data Collection and Database Development (Hospital Locations)

- Extract hospital location in Kedah and Selangor states from Google Map
- Develop a database table to store these locations
- The columns required in the database table are:
    o Hospital Name
    o Address (district, zipcode, state)
    o Longitude and Latitute
    o Type of Hospital (Private or Public hospital)

### **Week 2***: Data Collection and Database Development (Rainfall Volume)

- Set up an automated pipeline to extract data (rainfall volume) from two sources which are Google and Windy
- Clean and standardize data (e.g., format timestamps, unit conversions).
- Conduct a data quality check (missing values, inconsistencies, duplicate removal).
- Receive NAHRIM-provided data and ensure consistency with external sources.
- Store the collected data in a structured database for dashboard integration.

### **Week 3: Dashboard Development (Data Fusion & Display)

- Develop a prototype of the **spatial decision support dashboard**.
- Integrate **real-time rainfall volume data** from all two external sources and NAHRIM.
- Implement basic **GIS functionalities** to display spatial rainfall volume variations.
- Ensure **data refresh mechanisms** work correctly (real-time or scheduled updates).
- Validate dashboard data with **historical records or ground truth observations**.

### **Week 4**: Data Visualization & Initial Analysis

- Design interactive visualizations for rainfall volume variations across Kedah and Selangor.
- Implement charts, maps, and graphs for easier interpretation.
- Perform basic trend analysis (e.g., hourly and daily rainfall volume variations).
- Compare the forecasted rainfall volume data between the different sources.
- Generate initial insights for discussion with the supervisor/NAHRIM.


### **Week 5**: Final Validation & Report Writing

- Perform a final check on the **dashboard's performance and accuracy**.
- Ensure data consistency across sources and conduct a **cross-validation analysis**.
- Document the **data extraction methods, integration process, and visualization techniques**.
- Prepare a **project report** detailing methodology, results, challenges, and future work.
- Conduct a final **presentation/demo** for the project supervisor and NAHRIM.
